# Sorry We're Dead — Foundation 0.2.0

## Combat feedback pass

- Pistol shots now draw a short prototype bullet tracer and muzzle flash.
- Pistol impacts apply directional knockback and a brief hit-stun.
- Pizza Cutter Glaive swings now draw a temporary directional swing arc.
- Glaive impacts apply stronger knockback and a longer stagger than pistol shots.
- Zombies briefly flash red when damaged.
- Zombies now play a short placeholder fall/fade death response instead of disappearing instantly.
- Zombie attacks apply a small directional knockback/stagger to survivors.
- Zombies ignore already-downed survivors when choosing an active target.
- Removed the duplicate legacy zombie attack block from the AI script.

## All-players-down flow

- Human-controlled survivor prototypes register in the `active_players` group.
- `GameState` checks whether every active player is down.
- When every active player is down, gameplay pauses and a `SORRY WE'RE DEAD` overlay appears.
- The overlay offers `LOAD FROM LAST SAVE` and `QUIT`.
- The crosshair hides and the normal mouse cursor returns while the game-over overlay is open.

## Prototype checkpoint save

- `SaveSystem` writes a checkpoint to `user://last_save.json`.
- Combat Lab creates a checkpoint shortly after the scene loads.
- The checkpoint currently stores:
  - current scene
  - day/time
  - active-player position
  - health
  - pistol magazine ammo
  - pistol reserve ammo
- Loading the checkpoint reloads the gameplay scene, restores those values, and resumes the clock.
- Zombies are intentionally regenerated by the area spawner after loading rather than serialized individually. Full persistent world-state saving is a later milestone.

## Architecture note

`active_players` is deliberately separate from `survivors`. Future AI survivors can remain in the survivor simulation without counting as a human player for the all-players-down condition. Human-controlled survivors should join `active_players`; when every one of those controlled survivors is down, the failure screen appears.
