# Font setup

The project is configured to use **Press Start 2P** as the global UI font at:

`art/ui/fonts/PressStart2P-vaV7.ttf`

If that `.ttf` is not present after extracting a source package, copy the font file from your existing Sorry We're Dead project (or your original font download) into this folder using that exact filename.

The `.import` metadata and the included SIL Open Font License text are kept with the project so Godot can restore the existing font setup once the local font file is present.
