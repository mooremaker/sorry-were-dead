# Sorry We're Dead — Reboot Foundation 0.0.1

This is the clean foundation project for the Sorry We're Dead reboot.

## Game direction

A 2D pixel-art side-scrolling zombie survival shooter set in a living settlement outside New York City.

The main survivor runs **Sal's Slices**, while farms, the grocery store, armory, radio operator, town stockpile, homes, needs, relationships, and dangerous recovery missions create an interdependent settlement simulation.

Solo play uses AI-controlled worker-survivors.
Multiplayer lets humans take control of those same persistent survivors.

## Technical direction

- Godot 4.7.1 Standard
- GDScript
- Compatibility renderer
- 640x360 internal pixel-art canvas
- Server-authoritative multiplayer architecture
- Initial multiplayer target: 1–4 players
- Browser + Windows first
- Linux / Raspberry Pi ARM64 planned
- Mobile landscape planned later
