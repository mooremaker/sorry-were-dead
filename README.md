# Sorry We're Dead

Godot 4.7.x foundation for the 2D pixel-art zombie survival project.

Current playable prototype includes:

- Sal movement, jumping, crouch/sneak, sprinting, health, and downed state
- line-of-sight + noise-driven zombie AI
- multi-zombie spawning driven by WorldClock/ZombieDirector
- 360-degree mouse aiming with crosshair
- pistol ammo/reload/noise
- Pizza Cutter Glaive directional melee
- combat hit flash, knockback, stagger, tracer/muzzle feedback, and death feedback
- world day/time HUD
- all-active-players-down `SORRY WE'RE DEAD` failure screen
- prototype last-checkpoint save/load loop

See `docs/PACKAGE_0_2_0.md` for the first-run checklist and `docs/GAME_DESIGN.md` for the broader design foundation.
